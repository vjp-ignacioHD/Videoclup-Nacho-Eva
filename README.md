# Videoclup-Proyecto

Una aplicación web para gestionar una videoteca personal. Permite registrar películas, series y documentales, organizarlos por categorías y llevar un control de lo que has visto o deseas ver.

Ideal para amantes del cine y la organización digital.

---

## Funcionalidades

-  Añadir, editar y eliminar títulos (películas, series o documentales)
-  Clasificar por tipo de contenido
-  Marcar títulos como "vistos" o "por ver"
-  Búsqueda rápida por título
-  Almacenamiento local (usando `localStorage`)
